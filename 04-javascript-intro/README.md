## 📌 Overview
This module introduces JavaScript as the behavioral core of web applications. It covers core programming concepts including variable declarations (`let`, `const`), data types, `typeof` checking, arithmetic and logical operators, browser input/output handling, and basic DOM manipulation integrated with HTML/CSS interfaces.

## 🎯 Key Learning Outcomes
* Connecting JavaScript engines (V8) to HTML documents via `<script>` tags.
* Managing program memory safely using `const` and `let` following camelCase naming conventions.
* Working with fundamental data types (`string`, `number`, `boolean`, `undefined`, `null`).
* Performing arithmetic calculations, comparisons (`===`, `!==`), and logical operators (`&&`, `||`, `!`).
* Capturing user input values from HTML forms, converting types with `Number()`, and updating the DOM dynamically using `textContent` and `innerHTML`.
