## 📌 Overview
This directory contains practical evaluations focusing on Human-Computer Interaction (HCI), usability heuristics, accessibility guidelines (WCAG), and ergonomic standards (ISO 9241) applied to real-world academic software systems.

## 🎯 Key Learning Outcomes
* Identifying interface input and output elements.
* Evaluating software usability, error prevention, and cognitive friction.
* Analyzing accessibility implementations (screen readers, contrast, multimodal navigation).
* Applying ISO 9241 ergonomic principles (Effectiveness, Efficiency, and Satisfaction).
