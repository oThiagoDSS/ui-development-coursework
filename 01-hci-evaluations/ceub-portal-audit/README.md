## 🔍 Heuristic & Ergonomic Evaluation

### 1. Interface & Interaction
The interface provides interactive feedback when topics are accessed or completed by altering colors or messages. However, inconsistencies occur: accessing an unfinished task occasionally triggers a false completion flag in the system.

### 2. Usability
Key sections like "Secretariat" and "Financial" are explicitly structured. Nevertheless, freshman students face friction locating the "Online Classroom" (Sala Online), which is critical for daily coursework. This happens because the "Disciplines Panel" mixes grades, academic records, and intermittent syllabus links that often bypass the primary online classroom.

### 3. Accessibility
Sign language (Libras) and voice command tools are functional and helpful. Unfortunately, the accessibility options menu ("+ Accessibility") is partially obscured behind dialog elements on desktop viewports and conflicts on mobile devices. The cursor magnification feature triggers layout breaks and text overflow.

### 4. Ergonomics & Responsiveness
The color palette prevents eye strain, supported by a functional dark mode. However, deep navigation requires excessive click depth. Most actions perform smoothly, though QR code generation for campus entry experiences occasional latency on mobile networks.

### 5. ISO 9241 Compliance
* **Effectiveness:** High capacity to accomplish core goals (authentication, enrollment tracking, billing, and content access). However, mobile connection instability occasionally prevents students from safely fetching digital ID cards for campus access.
* **Efficiency:** Requires minimal clicks to reach target data on desktop platforms.
* **Satisfaction:** Friendly visual layout with intuitive information architecture.

---

## ⭐ Key Takeaways

* **Positive Highlight:** Integration of auxiliary tools like Libras, voice commands, and a comfortable dark mode tailored for long study sessions.
* **Critical Pain Point:** Task status feedback flaws, hidden accessibility overlays, and navigational friction preventing easy discovery of online classrooms for new students.

## 🏁 Final Conclusion
The portal exhibits a solid visual framework and a commendable commitment to inclusivity. Future updates should focus on fixing task completion tracking bugs, stabilizing mobile QR generation, and prioritizing the "Online Classroom" visibility to streamline daily academic workflows.
