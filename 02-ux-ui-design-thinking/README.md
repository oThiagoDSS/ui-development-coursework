## 📌 Overview
This module explores user-centered design methodologies through the **Design Thinking** framework (Empathize, Define, Ideate, Prototype, and Test). It focuses on identifying real-world UX friction, mapping user journeys, conducting competitive decision matrices, and building high-fidelity interactive wireframes.

## 🎯 Key Learning Outcomes
* Conducting field research, interviews, and real user pain point mapping.
* Building accurate user personas and end-to-end journey maps.
* Executing ideation sessions (Crazy 8s, Brainstorming) and evaluating solutions via decision matrices.
* Applying visual hierarchy (F/Z scan patterns) and WCAG accessibility standards (contrast, touch targets, multimodal design).
