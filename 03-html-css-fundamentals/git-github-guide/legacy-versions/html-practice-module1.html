Quick Guide: Essential Git and GitHub Commands

Git is a distributed version control system widely used in software development and web development. It allows developers to track source code changes, create recovery points in a project, and collaborate effectively with programming teams.

GitHub is a cloud-based platform that hosts Git repositories. It provides a graphical interface for managing code and interacting with other developers, making it an essential tool for building a professional portfolio in Systems Analysis and Development.

Step-by-Step Workflow (Git Workflow)

Follow the sequence below to prepare and upload your code changes to a remote repository:

  1. git status: Checks the current state of your files, including modified files, untracked files, and changes staged for commit.
  2. git add .: Adds changes in the current directory and its subdirectories to the staging area.
  3. git commit -m "message": Records the staged changes with a descriptive message explaining what was done.
  4. git push origin main: Uploads local commits to the remote repository on GitHub's main branch.

Useful Commands Summary

Command Description / Purpose
git init Initializes a new Git repository in the current project directory.
git clone [url] Creates a local copy of an existing repository hosted on GitHub or another Git server.
git checkout -b [name] Creates a new development branch and switches to it.
